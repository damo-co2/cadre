C · Switchboard

Mission control for people who like to see the wiring. Everything is monospace on a strict 8-pixel grid. Bots are live status tiles with activity sparklines; the conversation reads like a clean event log with tool calls inline; approvals sit in a queue on the right in amber. Keyboard first: one command bar does everything.

  • Type: JetBrains Mono everywhere, Space Grotesk for Bot names.
  • Feel: dense, fast, every action visible.
  • Chief: the wide tile on top of the board.
  • Events: log lines with timestamps; tool calls shown inline.
  • Status bar: routines due, model in use, phone connected.
